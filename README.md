# МИС «Цифровая клиника МК РАМН»

Учебно-симуляционный комплекс ведения медицинской документации стационара.
ФГБПОУ «Медицинский колледж» (МК РАМН). Учебная версия 1.2.

Демо в локальной сети колледжа: **https://sk.mkramn.ru/**

Комплекс работает автономно в браузере, без внешних серверов и интернета.
Все данные синтетические, обработка персональных данных не выполняется (ФЗ-152).

## Запуск

**macOS** — дважды щёлкните `start.command` в Finder.

**Windows** — дважды щёлкните `start.bat` (нужен Python 3, при установке
отметьте «Add Python to PATH»).

Скрипт проверяет наличие Python 3, запускает локальный HTTP-сервер на
`http://localhost:8080` и открывает браузер.

Остановка — закройте окно сервера (macOS — `Control + C` в Терминале).

Не открывайте `index.html` напрямую через `file://`: браузер заблокирует загрузку
форм из папки `forms/`.

## Возможности

- 23 интерактивных документа: 001/у, 003/у, 007/у, 008/у, 016/у, 066/у,
  004/у, 1-84, 366/у, 157/у и внутренние бланки 003/у.
- 4 клинических кейса с заложенными ошибками и режим «С нуля».
- Автоматическая перекрёстная проверка, оценка по 5-балльной шкале, отчёт TXT.
- Canvas-график температурного листа 004/у.
- Экспорт DOCX, печать/PDF, JSON-резервная копия.
- Учебная электронная подпись SHA-256 и журнал аудита.
- Светлая/тёмная тема, высокая контрастность, автодополнение МКБ-10,
  лекарств и диет, командная палитра `⌘K`.
- Панель преподавателя: кейсы, контрольный лист, статус ошибок.

## Тренажёр МИС–ЛИС для Moodle

`mis-lis-trainer.html` — самодостаточный тренажёр лабораторной информационной
системы. Открывается двойным щелчком в любом браузере, интернет и сервер не
нужны. Десять сценариев выстроены в производственную цепочку: карта пациента →
направление → передача в ЛИС → образец → брак → результаты → доставка в МИС →
исправление ошибки интеграции → итоговый самостоятельный цикл. Максимум
100 баллов; в конце студент скачивает TXT-отчёт и прикрепляет его к элементу
«Задание» в Moodle.
